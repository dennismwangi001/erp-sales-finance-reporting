# Project Self-Audit Checklist

Run through this before marking any project "done." If you can't check a 
box honestly, the project isn't finished - it's generic.

## Business Framing
- [ ] Business problem is stated as a real decision a company needs to make 
      (not "predict X" with no stakeholder context)
- [ ] 3+ specific business questions are listed
- [ ] Dataset is realistic and NOT an overused generic dataset (Titanic, 
      Iris, standard Kaggle Telco churn, etc.)

## Technical Depth
- [ ] Data cleaning steps are documented, not just performed silently
- [ ] Exploratory analysis is included and interpreted (not just plots 
      with no commentary)
- [ ] Statistical analysis is used where it strengthens the answer 
      (hypothesis tests, confidence intervals, etc.)
- [ ] SQL analysis is included and shown as actual queries, not just 
      "used SQL to extract data"
- [ ] Python/R analysis is present and adds something SQL alone couldn't
- [ ] Advanced modeling (ML/forecasting) is used ONLY if it's the right 
      tool for the question - not added just to look advanced
- [ ] Dashboard (Power BI/Tableau) has clear KPIs, not decorative charts

## Business Output
- [ ] Insights are specific and numeric (e.g. "churn is 23% higher in 
      segment X"), not vague ("there are some patterns")
- [ ] Each recommendation is directly tied to a specific insight above
- [ ] Recommendations are things a business could actually act on

## Presentation & Job-Readiness
- [ ] README fully follows the project template structure
- [ ] I can map this project to 3+ specific skills from the job market 
      skills matrix
- [ ] I have a 2-3 minute spoken explanation of this project ready 
      (problem -> approach -> insight -> recommendation)
- [ ] I have 1-2 CV bullet points drafted from this project 
      (action + tool + business outcome)
- [ ] Someone else could re-run this analysis from the README alone

## Final Check
- [ ] If I show this to my mentor again, would he call it "generic" or 
      "realistic"? Be honest.
